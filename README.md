# Hospital Management System

A desktop-based Hospital Management System built using Java and Swing to efficiently manage hospital operations such as patient records, doctor management, appointments, and billing.

## Features

- Patient Registration & Record Management  
- Doctor & Staff Management  
- Appointment Scheduling  
- Billing & Payment Handling  
- User-friendly GUI (Java Swing)  
- Search, Update, and Delete Records  

## Tech Stack

- Language: Java  
- GUI: Java Swing  
- Concepts: OOP, Event Handling, Database (if used)

## How to Run

1. Clone the repository  
2. Open in IntelliJ
3. Run the main class  

## Objective

To develop a user-friendly hospital system that applies Object-Oriented Programming concepts and provides efficient data management through a graphical interface.
